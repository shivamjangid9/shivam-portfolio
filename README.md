# Shivam Jangid - Portfolio (React + Vite)

## Chalane ka tarika
1. Node.js (v18+) install hona chahiye.
2. Terminal me is folder me jao aur chalao:

   npm install
   npm run dev

3. Browser me http://localhost:5173 kholo.

## Apna content badalna
`src/data.js` kholo: naam, about, skills, projects, GitHub / LinkedIn links, resume sab wahin se change hota hai.
Resume ke liye PDF ko `public/resume.pdf` me rakho aur data.js me `resume: "/resume.pdf"` likho.

## Live karna
npm run build  ->  `dist/` folder ko Vercel ya Netlify par upload kar do.
